# Responsive-Music-Player ( Anibeats ) 
Welcome to **ANiBEATS**, a stylish and interactive anime-themed music player built with **HTML**, **CSS**, and **JavaScript**. Enjoy a smooth user experience with keyboard shortcuts, animated UI, and extra touches like anime facts and a chatbot interface!
**Features**
a) **Play/Pause, Next/Previous, and Loop** buttons
b) **Lyrics Display** — shows full lyrics when available
c)  **Dynamic Backgrounds** — smooth color transitions
d) **Keyboard Controls**
e) **Chatbot Toggle** — UI prepared for future AI assistant
f) **Anime Facts Box** — appears when song is paused.
g) **Fully Responsive Design** — optimized for all screen sizes
